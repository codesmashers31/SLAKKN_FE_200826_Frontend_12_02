1.Why did people need websites?

Before websites, information was mainly shared through books, newspapers, letters, telephone calls, and physical documents. "What if we could store information on computers and allow other people to access it?" This created the need for a system to share information between computers.

2.What was the first major idea?

Scientists and researchers were working with many documents and computers. They needed an easy way to: Store information Find information Connect one document to another Share information with other researchers So the idea of hypertext became important.

3.What is Hypertext?

Hypertext means text that can connect to another piece of information. For example: "Click here to learn about Computers." When you click it, you go to another document. That clickable connection is the basic idea behind the link we use on websites today.

4.Who created the World Wide Web?

In 1989, Tim Berners-Lee proposed the World Wide Web while working at CERN. His basic idea was: "Let's create a system where documents can be connected using links and accessed through a network."
