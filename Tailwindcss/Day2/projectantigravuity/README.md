# AI WAR 2030: OpenAI vs Anthropic vs Google Gemini
### The Future of Artificial Intelligence & The Developer Survival Guide

A modern, futuristic, production-grade intelligence platform and developer survival guide analyzing the frontier AI race between **OpenAI**, **Anthropic**, and **Google Gemini**, the evolution toward **2030**, multi-agent systems, workforce transformations, and concrete roadmaps for software engineers.

---

## 🌌 Key Highlights & Features

1. **Frontier AI War Matrix (`/ai-war`)**
   - Head-to-head qualitative and verified comparison across Reasoning, Coding, Multimodal AI, Voice, Agents, Tool Use, Enterprise Scale, Research, and API protocols.
   - Strict data policy: zero synthetic unverified benchmark numbers.

2. **AI Model Intelligence Center (`/models`)**
   - Registry of foundation models (Claude 3.7 Sonnet, o3-mini, GPT-4o, Gemini 2.0 Flash, Gemini 1.5 Pro, DeepSeek R1).
   - Interactive 3-model side-by-side comparison drawer.

3. **AI Evolution Timeline (`/timeline`)**
   - Visual trajectory from 2020 through 2030 with explicit distinction between historical breakthroughs and speculative 2027–2030 scenarios.

4. **The Road to 2030 (`/future-2030`)**
   - 8 in-depth technology scenarios (Personal Agents, Agentic Software Dev, AI-Native Companies, Personalized Education, Robotics, Multi-Agent Swarms, Ambient OS, Human+AI Symbiosis).
   - Interactive 2026–2030 Horizon Slider with dynamic radar metrics.

5. **Developer Survival Guide (`/developer-2030`)**
   - "Will AI Replace Developers?" thesis.
   - 5-stage transformation ladder (Traditional -> AI-Assisted -> AI-Native -> Agent Engineer -> AI System Architect).
   - 7-Level mastery curriculum from foundations to 2030 AI Architect.
   - Old vs Future workflow comparison flowchart.

6. **AI Job Impact Center (`/jobs`)**
   - 12+ analyzed professions mapped across Low, Moderate, High transformation tiers.
   - 14+ emerging AI era careers (Agent Engineer, AI Security Red-Teamer, Eval Engineer, Synthetic Data Architect, etc.).

7. **Developer Skill Gap Analyzer (`/skills`)**
   - Interactive diagnostic tool with role selector and skill checkboxes.
   - Calculates custom AI Readiness Score (0–100%) and generates a personalized 2030 action plan.

8. **AI Agent Lab (`/agents`)**
   - Interactive multi-agent architecture topology.
   - "Build Your AI Team" simulator with custom agent selection and execution stream.

9. **Research & Resources (`/resources` & `/about`)**
   - Seminal papers (Attention Is All You Need, Scaling Laws, ReAct, Constitutional AI), Model Context Protocol (MCP) standards, and evaluation methodology.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion, Lucide React, Recharts, Canvas Confetti, React Router DOM
- **Backend**: Node.js, Express.js, CORS, Dotenv
- **Theme**: Dark futuristic cyberpunk/Bloomberg intelligence palette (`#050816` background, `#0B1020` secondary, `#11172A` cards, OpenAI emerald, Anthropic amber, Gemini blue/purple, 2030 cyan/violet).

## 🚀 Quick Start Guide

### 1. Start the Express API Backend
```bash
cd server
npm install
npm start
# Server runs on http://localhost:5000
```

### 2. Start the Vite React Frontend
```bash
cd client
npm install
npm run dev
# Frontend runs on http://localhost:3000
```
